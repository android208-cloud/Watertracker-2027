# Архитектура Watertracker-next

## Карта модулей
Каждый модуль — один файл `src/mNN-имя.js` + контракт(ы) из реестра + секция
стенда. Никаких querySelector-водителей через чужие узлы: связи только через
явные вызовы контрактов модуля.

- M01 core-state: состояние, save, миграции схем (C-020). [ГОТОВ, bench 20/20]
- M02 storage-keys: ключи, атомарность, квоты. [ГОТОВ, bench 20/20]
- M03 journal: лента порций, правки, дубли (C-024, C-002).
- M04 drinks-catalog: напитки, гидратация, иконки.
- M05 cup-art: слои кота, маска силуэта (C-017).
- M06 water-solid: уровень, лифт, однотонная заливка, глубокая линия замыкания.
- M07 wave: путь гребня, слои, запечённые кейфреймы, волнистый верх пояса,
  папка настроек волны, диагностика (C-019).
- M08 belt-color: рампа поясов, водитель пояса и цвета (C-004).
- M09 bubbles: пузырьки поверх морды.
- M10 stats-zones: статистика, зоны (C-009), потолок (C-004).
- M11 chart: график дня/недели, стадион, сетка.
- M12 pace-predictor: темп и предиктор (C-005, C-006).
- M13 reminders: напоминания и тексты по случаям (C-005).
- M14 cloud: Google-пак watercat-24 + lc, тишина (C-015, C-020).
- M15 themes-settings: темы, ночной фильтр, папки настроек (C-007…C-012, C-016).
- M16 onboarding: онбординг-макет, restore без онбординга (C-014).
- M17 shell: статус-бар, иконки, стартовое окно (C-010, C-011, C-012) + Android-мосты.
- M18 diagnostics: паспорт устройства и живых узлов (C-019).

## Стенд (bench)
Прогон: store-JSON (cup-tracker-v1 + cup-liquid-color-v1) → headless-рендер →
`bench/shots/<tag>.png` + отчёт `bench/reports/<tag>.json`:
- уровень: data-wp, transform лифта;
- слои волны: имя анимации, длительность, статус, сдвиг за 1 s (px/s);
- геометрия кромки по path (getPointAtLength): размах вверх/вниз от ватерлинии
  (WT_HEAD=24), доля плоских точек (детектор «среза»);
- пояс: y1/y2 градиента, число стоп;
- цвета: кромка/пояс/пилюли по пикселям снимка (точечно, по запросу).
Базовая линия снимается с ДОНORA (старый www); модуль принят, когда его числа
равны базовой линии в допуске (размах ±0.5 ед., скорость ±5%, плоскость ≤ той же)
И глаз владельца согласен.

## Порядок переноса
1) M01+M02 (ядро и ключи) → 2) M06+M07+M08 (вода и волна, первый полный модуль
со стендом) → 3) M03+M04 → 4) M10+M11+M12 → 5) M13 → 6) M14 → 7) M15 →
8) M05+M09 → 9) M16+M17+M18. Оболочка APK собирается, когда M01–M08 зелёные.
